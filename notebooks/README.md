# Notebooks

Jupyter notebooks in this directory are experiment drivers, not deliverables.
Each notebook should:

- be self-contained and reproducible with seeded runs,
- start with a short plain-language goal statement,
- reference the relevant README mechanism and ROADMAP milestone,
- save any figures to the `notebooks/` directory or a defined output folder,
- not commit generated data or large figure binaries (see .gitignore).

Notebooks are for exploration; any logic that becomes stable should move into
`bio_network/` and be covered by tests in `tests/`.

There are no notebooks yet. They will be added as milestones land.
